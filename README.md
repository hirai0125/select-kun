# セレクト君

観光・買い物・食事・温泉・風呂・釣りなど、ジャンル別のオススメ場所を登録して、近畿地方の地図にピンで表示し、Googleマップでナビできるアプリです。

- 公開URL：https://hirai0125.github.io/select-kun/
- Androidは Chrome で開き、メニュー「ホーム画面に追加」（または「アプリをインストール」）でアプリとして使えます
- データはスマホ内に保存されます。機種変更時は「出力・設定 → バックアップ保存」を使ってください
- 地図：国土地理院タイル／地図表示：Leaflet

## PC・スマホの同期（Googleスプレッドシート）
1. 新しいGoogleスプレッドシートを作り「拡張機能 → Apps Script」に `Code.gs` の中身を貼り付け、`KEY` を合言葉に変更
2. デプロイ → 新しいデプロイ → ウェブアプリ（実行：自分／アクセス：全員）
3. 表示されたURL（…/exec）と合言葉を、アプリの「出力・設定 → PC・スマホの同期」に入れて「保存して接続」
